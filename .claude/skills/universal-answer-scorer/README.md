# 🧠 通用答卷评分技能

## 📋 技能概述

这是一个完全独立的通用答卷评分技能，能够自动识别答卷类型，选择相应的权威专家角色，严格按照评分标准对答卷进行精确评分。技能专注于给出各题目的分数，采用温度0.1的严格标准。

## ✨ 核心特性

### 🎯 自动类型识别
- **国情知识测试**: 识别中国历史、地理、政治、文化相关问题
- **大五人格测试**: 识别人格特质和性格评估问题
- **客服能力测试**: 识别客户服务和沟通相关问题
- **认知偏差测试**: 识别逻辑思维和认知能力问题
- **通用评估**: 处理其他类型的评估问题

#### 1. 国情知识专家

## 🔬 评分算法

### 严格评分标准
- **温度参数**: 0.1（极其严格）
- **评分范围**: 0-10分（精确到0.1分）
- **评分依据**: 严格按照每道题的评分标准

### 核心评分因子

#### 1. 关键词匹配度
```python
if expected_keywords:
    keyword_score = (len(keywords_found) / len(expected_keywords)) * 10
```

#### 2. 答案完整性
- **>100字符**: +1.0分
- **>50字符**: +0.5分
- **<10字符**: 基础分3.0分

#### 3. 专业性指标
检测逻辑连接词：因为、所以、首先、其次、最后、总之等
- **≥2个专业指标**: +0.5分

### 评分输出格式
```json
{
  "question_id": "history_1",
  "score": 8.5,
  "max_score": 10,
  "reasoning": "关键词匹配：3/4 (造纸术, 指南针, 火药); 缺失关键词：印刷术; 答案长度：85字符; 展现专业分析能力",
  "keywords_found": ["造纸术", "指南针", "火药"],
  "keywords_missing": ["印刷术"],
  "dimension": "historical_knowledge"
}
```
