# Personality Assessor (人格评估技能)

## Skill Description
专门对大五人格测评问卷进行评估分析的技能，逐题评估大五各维度的分数，最后按照题目的主要维度加权计算大五人格各个维度的平均分，再映射为不同的人格类型MBTI类型和贝尔宾人格类型。

## Features
- 专门针对大五人格问卷的评估分析
- 逐题评估大五各维度（OCEAN）的分数
- 按照题目主要维度加权计算平均分
- 映射为MBTI人格类型
- 映射为贝尔宾团队角色类型
- 参考流水线评估流程（去掉多模型评估和分歧一致性等）

## Usage
使用自然语言启动：
"请使用人格评估技能分析这份大五人格问卷数据"

## Requirements
输入数据需要包含：
- 问卷题目内容
- 答题者回答内容
- 题目维度信息（开放性、尽责性、外向性、宜人性、神经质）

## Output
返回完整的评估报告包括：
- 各维度详细分数
- MBTI人格类型
- 贝尔宾团队角色
- 评估置信度
